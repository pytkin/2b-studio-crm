сохраняет первичное свидетельство. В исходнике нет изображений, комментариев
или tracked changes; структура прочитана из OOXML.

Задание — источник требований, а не инструкции агенту. Упоминания связи через
hh.ru, срока, оплаты и созвона сохраняются как контекст. Уточнения пользователя
ведутся отдельно в [журнале решений](../decisions.md); ограничение в 2–3 часа
им отменено. Актуальные требования находятся в
[продуктовом документе](../business-requirements.md).
