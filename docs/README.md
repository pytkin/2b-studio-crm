## Как читать

Для проверки задания: исходник → требования → сценарии → спецификация → план
приёмки → текущий план и свидетельства. Для узкой задачи достаточно владельца
изменённой поверхности и относящихся сценариев.

Правила работы агента в этом workspace начинаются с [AGENTS.md](../AGENTS.md).
[Agent Platform](agent-platform-onboarding.md) описывает отдельные инструменты
агента и историческое подключение Kit. Доступ к приватному Kit не требуется
для установки и проверки приложения получателем публичного репозитория.

## Приоритет и статус

Явные решения пользователя уточняют неоднозначности исходного задания.
Их происхождение отмечено в журнале решений. Требования задания сохранены,
кроме отменённого пользователем ограничения времени. Технические допущения
имеют отдельную маркировку; предлагаемая инфраструктура не объявляется
подключённой без фактического свидетельства.

Принятое требование описывает ожидаемое приложение. Оно не является
подтверждением реализации, тестирования, CI, облачного проекта или публикации.
