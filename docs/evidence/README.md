# Свидетельства проверок

Последняя зафиксированная приёмка поставки относится к ревизии приложения
`58792965e03bc4184f42ee0a5344dfa9f394e7d8`:
[облачное демо, GitHub, HTTPS и браузерный цикл desktop/mobile](cloud-deployment/README.md).
Текущий статус разработки ведётся в [плане](../implementation-plan.md),
связь требований с проверками — в [матрице приёмки](../acceptance-plan.md).

| Материал | Назначение и граница |
|---|---|
| [Поставка S8](cloud-deployment/README.md) | Проверенная ревизия, Cloud/API, свежий HTTPS clone без Kit, браузерный цикл и снимки |

| [Браузерный UI/UX-проход](ux-browser-current/README.md) | Последующий локальный аудит desktop/mobile, формы, фокус, отказ и восстановление |

количество миграций и состояние сервисов относятся к указанным ревизиям;
исторические отчёты не являются текущим статусом. Свежий прогон выполняется по
[локальному руководству](../local-development.md).

## Историческая локальная приёмка 8126dbd, 4 ноября 2026

Более поздние локальные исправления приведены в [ревью 96a87e3](review.md),
последующая внешняя приёмка — в [отчёте S8](cloud-deployment/README.md).

Код приложения, миграции и запускающие команды проверены на ревизии `8126dbdb84f1e82f3ea0211a94b96e4b6b7bacbe`.
Для прогона использован чистый локальный clone. В нём исходно отсутствовали node_modules,
инициализированный приватный Kit и файл демо-доступов. Первая команда была
`pnpm demo:start`. Она установила зависимости, подготовила Supabase, собрала SPA
и открыла локальный адрес. Повторный запуск сохранил тот же набор пользователей,
объектов, задач и событий.

| Проверенная граница | Наблюдение |
|---|---|
| Демо на 127.0.0.1:5173 | Вход и выход трёх аккаунтов, открытие прямой ссылки, доступность собственной истории, недоступность чужой задачи. Постановщик видел 3 объекта и 3 задачи. Исполнители видели соответственно 2/2 и 1/1. Файл доступов имел права 0600. |
| Приложение | Frozen install, форматирование, lint, строгая типизация, 15 тестов инфраструктуры и 51 тест Vitest/RTL/MSW. Production build и проверка артефактов на секреты завершились успешно. |
| База | Восемь миграций с нуля на выделенном test project. 290 проверок pgTAP, 22 проверки SDK/REST, наблюдаемые ожидания в двух соединениях, конкуренция и потеря HTTP-ответа после commit. |
| Браузер | 16 вариантов Playwright. Реальные Supabase Auth и PostgreSQL, production bundle, Chromium при 1440×900 и 360×800. Истечение настоящего JWT, 10-секундный таймаут удержанного HTTP-запроса, явный повтор с тем же UUID, фокус и клавиатурное подтверждение. |
| Завершение | В тестовой БД пусты Auth, профили, объекты, задачи и история. Git-дерево clone чистое. Веб-сервер и обе среды остановлены, демо-данные сохранены. |

[Журнал команд с кодами возврата, длительностью и результатами](verification.json).
Дополнительное чтение демо под тремя ролями и снимки выполнялись из браузера
временным операторским драйвером. Для ручного повтора откройте по очереди все три
аккаунта из файла доступов, сравните список объектов и попробуйте прямую ссылку
на поручение другого исполнителя. Автоматический сквозной прогон входит в
`pnpm test:e2e`.
