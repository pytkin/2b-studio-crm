# Локальная приёмка, 4 ноября 2026

Более поздние исправления и результаты для всех сценариев приведены в [повторном ревью](review.md).

Код приложения, миграции и запускающие команды проверены на ревизии `8126dbdb84f1e82f3ea0211a94b96e4b6b7bacbe`.
Для прогона использован чистый локальный clone. В нём исходно отсутствовали node_modules,
инициализированный приватный Kit и файл демо-доступов. Первая команда была
`pnpm demo:start`. Она установила зависимости, подготовила Supabase, собрала SPA
и открыла локальный адрес. Повторный запуск сохранил тот же набор пользователей,
объектов, задач и событий.

| Приложение | Frozen install, форматирование, lint, строгая типизация, 15 тестов инфраструктуры и 51 тест Vitest/RTL/MSW. Production build и проверка артефактов на секреты завершились успешно. |
| База | Восемь миграций с нуля на выделенном test project. 290 проверок pgTAP, 22 проверки SDK/REST, наблюдаемые ожидания в двух соединениях, конкуренция и потеря HTTP-ответа после commit. |
| Браузер | 16 вариантов Playwright. Реальные Supabase Auth и PostgreSQL, production bundle, Chromium при 1440×900 и 360×800. Истечение настоящего JWT, 10-секундный таймаут удержанного HTTP-запроса, явный повтор с тем же UUID, фокус и клавиатурное подтверждение. |
| Завершение | В тестовой БД пусты Auth, профили, объекты, задачи и история. Git-дерево clone чистое. Веб-сервер и обе среды остановлены, демо-данные сохранены. |
